# 接口冻结：W8 外壳功能层（作品中心 / 备份恢复 / 设置 / 首启向导）

本文件是 W8 波次并行开发的**权威契约**。功能智能体只写自己的 `.vue` + `-model.ts` + 测试；
`features/ports.ts`、`App.vue`、`main.ts`、`theme/**`、`features/{types,settings-store}.ts` 归 Lead 独占。

## 0. 通用铁律

1. 组件**只依赖 props 传入的端口接口**（`features/types.ts`），不得 import `node:`、不得 import `@yfe/contracts`、
   不得直接调 `window.yfe`、不得自己 new client。
2. 端口**不抛异常**，一律返回 `FeatureResult<T>`；组件必须处理 `ok:false` 并把 `message` 显示给用户
   （`code` 可放在 `title` 或小字里，不要只显示 code）。
3. 所有用户可见文案用中文；空数据、未配置、失败三条路径都必须有明确说明文案，不能白屏、不能静默。
4. 样式只用 `--yfe-*` 变量（`packages/ui/src/tokens.ts` 的键名），不写死颜色（除 `var()` 的 fallback）。
5. 组件内部状态一律局部 `ref`；**不直接读写 localStorage**（设置项必须经 `SettingsPort`）。
6. 不新增 `AppState` / `AppSnapshot` / `RendererClientPort` 的成员（会打红 15 个测试夹具）。
7. 文件所有权：只写自己的文件；共享文件（`types.ts`、`settings-store.ts`、`ports.ts`、`App.vue`）只读。

## 1. 组件契约（props / emits 必须逐字一致，Lead 按此接线）

### 1.1 `features/project-hub.vue` —— 作品中心（差距报告 B 项）

```ts
props: { hub: ProjectHubStore }
emits: {
  open: []            // 打开作品（Hub 内部已调 hub.open，此事件只通知外壳切到编辑器）
  backups: []         // 请求外壳切到备份面板
  close: []           // 关闭作品中心回到编辑器
}
```

- 结构照上游 `upstream/src/components/app/ProjectHub.tsx`：分组列表（完整项目 / 自定义项目，组头带计数胶囊）、
  卡片（名称 + `N 卷 · N 章 · N.N 万字` 统计若端口无数据则显示名称与简介即可、摘要两行截断、
  「创建于 X · 最近活动 Y」）、卡片底部操作按钮（打开 / 备份与恢复 / 编辑 / 删除）。
- 新建表单：顶部标题「新建小说项目」、名称输入（空名报「请输入书名」）、项目形态二选一
  （完整项目 / 自定义项目）、简介（可选）、「创建」按钮。
- 编辑：行内改名（空名报「请输入书名」），保存走 `hub.rename`。
- 删除：danger 确认「确定删除项目「X」？其全部设定、大纲与正文将一并删除，不可恢复！建议先导出备份。」，
  确认后 `hub.remove`。
- 空态：虚线框「还没有作品，点击右上角「新建小说项目」开启第一本书」。
- 加载态：`snapshot.loading` 为真时显示「加载中…」（首次加载不得闪空态）。
- 失败：`snapshot.lastError` 非空时显示 `message` + 重试按钮（调 `hub.refresh()`）。

### 1.2 `features/backup-manager.vue` —— 备份与恢复（差距报告 L 项）

```ts
props: { backup: BackupPort }
emits: { close: [] }
```

- 顶部按钮「立即备份」（`backup.create(label?)`，成功后提示路径与体积、耗时）。
- 列表：每项显示标签（无标签用文件名）、创建时间（`createdAt:null` 显示「时间未知」）、体积、
  以及**可恢复性**：`readable:false` 的项必须显示成「不可恢复（缺清单）」并**禁用恢复按钮**，
  不得隐藏该项（它可能是迁移器留下的迁移前快照）。
- 校验按钮 → `backup.verify(backupPath)`；展示 `integrity` / `databaseSchemaVersion` / `needsMigration`。
- 恢复按钮 → 二次确认文案必须写明「恢复不会覆盖当前库，会写入恢复预览目录」；成功后显示 `targetPath`。
  恢复前要求用户勾选确认复选框（或输入确认文本），防误触。
- 空态：「还没有备份，点击「立即备份」创建第一份」。

### 1.3 `features/settings-panel.vue` —— 设置（差距报告 H 项）

```ts
props: { settings: SettingsPort; themes: readonly ThemeOption[] }
emits: { change: [view: AppSettingsView]; close: [] }
```

- `ThemeOption` 由 Lead 从 `theme/palettes.ts` 生成：`{ id: string; name: string; desc: string; swatch: string }`。
- 分区：主题（9 个色块单选，含自定义时禁用并标注「暂未实现」）、界面缩放（80~160%，步进 10，
  显示「自动」开关，`zoomManual=false` 时显示自动值且不可手改）、字体（预设字体下拉 + 字号）、
  侧栏宽度（滑块 200~560）。
- 任何改动：调 `settings.save(patch)` → 用返回的 `AppSettingsView` 更新本地状态 → `emit('change', view)`。
- 「恢复默认」按钮 → `settings.reset()` → `emit('change', view)`。
- 缩放上下限必须有禁用态（到达 80% / 160% 时对应按钮 disabled）。

### 1.4 `features/welcome-wizard.vue` —— 首启欢迎向导（差距报告 A 项）

```ts
props: { welcome: WelcomePort }
emits: { done: [payload: { projectId: string | null }]; close: [] }
```

- 三选一入口（照上游 WelcomeWizard）：① 新建作品（交给作品中心）② 创建示范项目
  （`welcome.createDemoProject()`，成功后 `emit('done',{projectId})`）③ 直接开始（`emit('done',{projectId:null})`）。
- 示范项目按钮：确认文案「创建示范项目「吞天神脉」？包含两卷二十章正文（约九万字）与全套设定。」
- 「不再显示」复选框 → 勾选时调 `welcome.markSeen()`（未勾选也应允许继续，只是下次仍出现）。
- 向导完成（任意路径）必须调 `welcome.markSeen()`，避免每次启动都弹。
- 不要求 AI 配置步骤（W8 不做；配置入口在模型设置面板）。

## 2. 测试要求（每份交付 2 个文件）

- `<name>.test.ts`：纯逻辑/model 层（用假端口，覆盖成功 / 失败 / 空数据 / 边界）。
- `<name>.view.test.ts`：`// @vitest-environment happy-dom` + `@vue/test-utils` 挂载，
  断言可见文本、交互回调、禁用态、失败提示。
- 断言不得写死「共 N 项」以外的实现细节；不得 `skip`。
- 自验命令（各自持锁跑）：
  - `npx vitest run --project desktop apps/desktop/tests/features/<name>.test.ts apps/desktop/tests/features/<name>.view.test.ts`
  - `npx tsc --noEmit -p _scratch/tsconfig.w8-<short>.json`（0 error）
