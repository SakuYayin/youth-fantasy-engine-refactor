# uni-app x 移动端开发设计

## 定位与工具链

首发只做 Android。配置查看、基础编辑、同步触发和远程控制优先，桌面复杂资料编排和插件开发不移植到手机。最低 Android 版本由正式工具链、数据库及后台插件支持矩阵决定；用户提供的小米 15 Pro、澎湃 OS 4、Android 17 为首轮真机，不等于唯一支持系统。

采用 uni-app x 原生渲染路线，优先验证受维护的蒸汽模式正式工具链。官方当前已区分 VDOM 和蒸汽模式，并说明维护方向；不能将其统称为“所有业务编译为 Kotlin”。蒸汽模式业务可使用 JS/TS，UTS 原生插件负责 Kotlin 能力。P0 锁定 HBuilderX、编译模式、Android SDK、Gradle、JDK 和依赖版本，记录构建输出及原生插件兼容结果。[官方概述](https://doc.dcloud.net.cn/uni-app-x/)

不能因某个 npm 包可安装就认为 Android 可运行。直接依赖 DOM、Electron、Node、原生 Node 扩展的包不进入移动业务模块；纯工具、Schema 和生成 SDK 逐项编译验证。桌面 Vue 组件与 CodeMirror 不直接运行在手机原生控件中。

## 页面与功能

| 页面 | 首版内容 |
| --- | --- |
| 作品 | 绑定工作区、缓存作品与章节概要、下载选择 |
| 基础编辑 | 正文、基本选区、撤销、字数、本地保存与冲突提示 |
| 配置 | 主题、模板、工作流与兼容插件状态；设备设置单独管理 |
| 任务 | 查看本机/后端/指定桌面的任务、取消和结果 |
| 同步 | 配对、最近状态、手动触发、待上传、错误诊断 |
| 设备控制 | 在线状态、允许的工作流、暂停任务、同步命令与回执 |

首次进入可先建本地草稿，再选择连接服务。扫码只导入短期配对信息，展示服务地址并确认；禁止二维码夹带长期 NAS 密码。需要登录时通过 API 完成，不依赖浏览器登录页跳转来冒充 WebDAV 认证。

## 本地保存

定义 MobileRepository，与 UI 分离。SQLite 原生适配提供作品概要、下载正文、草稿、版本、outbox、附件缓存与游标。UTS/Kotlin 封装事务；选用 Android SQLite 或 Room 的实现须在 P0 固定，不要求手机加载 better-sqlite3。

正文、revision 和 outbox 在同一事务保存。单纯异步 KV 或多个 storage.set 操作不等价于这一事务。前台与 WorkManager 通过同一移动数据模块访问数据库，采用序列化写事务；不能各自维护一套独立同步状态。

用户明确选择可离线章节。缓存淘汰不删除未同步草稿、冲突版本或待上传附件。图片按需获取，限制流量与缓存；下载过程文件使用临时名，校验后发布。设备空间不足时先报告保存失败，不标记“已保存”。

## 原生模块接口

| 能力 | 接口职责 | 平台实现 |
| --- | --- | --- |
| database | 事务化命令、查询、迁移与恢复 | UTS/Kotlin SQLite 适配 |
| secureStore | 密钥、设备凭据引用、撤销清理 | Android Keystore 与受保护存储 |
| fileAccess | 用户选文件、导入导出、持久 URI 授权 | 系统文件选择器，不要求全盘权限 |
| backgroundSync | 唯一同步任务、网络约束、重试与取消 | WorkManager |
| editor | 基础输入、选区、撤销与组合态 | 内置原生编辑控件，必要时封装 EditText |

基础输入不能通过网络保存回包反复替换控件全文。锁屏、切页或进程回收时，以最近已确认事务和可恢复草稿为准。长文本验证不通过时拆分章节或使用原生控件扩展，不临时改成不可控的整本单文本框。

## 同步与后台

手机默认接入统一 HTTPS 后端；WebDAV 直连作为经验证的扩展。SMB/SFTP/NFS 优先经 NAS 后端代理，不承诺首版 Android 具备全部协议直连。共享 API 同步基础编辑与配置，不将服务器文件路径暴露给界面任意访问。

前台触发与后台同步共用 workspaceId、deviceId、opId、cursor。WorkManager 使用每工作区唯一任务，失败按网络约束与指数退避重试；推送仅作为提示，不作为数据真相。系统可能延迟后台工作，用户强行停止应用后不能承诺自动唤醒或实时同步。[Android 持久后台任务](https://developer.android.com/develop/background-work/background-tasks/persistent)

默认 HTTPS 和系统证书校验。局域网明文 HTTP 如提供，必须是用户明确开启的局域网选项并配合 Android 网络安全策略，不能默认全局明文放行。自签服务使用受信任 CA/明确导入信任配置，不提供全局忽略所有证书错误开关。

## 远程控制与插件

控制对象明确区分后端任务与桌面任务。发给桌面的命令带目标设备、允许命令 ID、有效期和 requestId；桌面关闭时显示待处理或过期，后台不是远程开机工具。界面不可发任意 shell、文件路径和脚本。

主题、模板、工作流与插件清单采用同一声明式格式。手机能力不足时显示只读、不可用或远程执行，保留原数据。新的 UTS 原生模块随 APK 编译发布；桌面业务 JS/Vue 插件不自动在手机热加载。

## 真机验收

覆盖首次配对、离线编辑、桌面同章冲突、图片下载中断、设备撤销、手机时间错误、锁屏、省电、进程回收、重连和系统输入法。先用小米默认后台设置测量，再决定提供哪些系统设置指引；不以关闭全部省电限制作为唯一通过条件。

Android Studio/SDK 尚需安装或按正式打包方式准备。先完成调试 APK，再验收签名 release APK；签名密钥单独保管和备份，禁止写入仓库。包体同时报告 APK 下载量、安装占用与可选缓存，性能用 release 包测量。
