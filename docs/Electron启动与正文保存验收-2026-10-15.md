# Electron 启动与正文保存验收

2026-10-15，Windows 11 Insider 10.0.29639，Electron 44.7.2。

## 结果

默认 Chromium 沙箱开启，真实窗口、preload、Vue、CodeMirror、CSP 与 SQLite 链路通过。通过界面按钮新建作品和章节，原生输入中文、emoji 与换行，Ctrl+S 保存成功；重新加载页面以及整个 Electron 退出后重新启动，完整正文均可读回。

## 三个实际问题与修复

1. **运行时继承工作区的 Low Integrity ACL。** 仓库根显式带 Low Mandatory Level，Electron 可执行文件继承后使主进程降为 Low；它不能写普通用户目录及系统 TEMP，因此 SQLite 的临时表/用户数据目录报 SQLITE_CANTOPEN。中文路径本身无编码缺陷：同一官方运行时放到普通用户目录后，中文数据库、WAL、中文与 emoji 往返及 8 MiB 磁盘临时表全部成功。只提高单个 exe 的完整性仍会出现 renderer 崩溃；完整干净运行时则默认沙箱通过。
2. **ESM 启动死锁。** 主入口顶层 await runElectron，而 runElectron 等 app.whenReady；Electron 等入口完成求值后才继续 ready。改为异步启动回调，让入口完成求值。正常退出先完成保存和 worker 关闭，再 app.quit，避免 process.exit 截断 Chromium 的 localStorage 持久化。
3. **界面草稿幂等键不符合契约。** 原先 draft:session:document:sequence 含冒号，被 ID 校验拒绝，实际界面报 VALIDATION_MALFORMED_ID。改用契约允许的下划线，保持同一会话/文档/序号的稳定重放语义。新增真实 AppState → worker → 应用用例 → SQLite 的保存/重新加载回归。

Windows 开发启动器现将完整运行时按全部文件内容和相对路径 SHA-256 缓存在 `%LOCALAPPDATA%/YouthFantasyEngine/electron-runtime/<摘要>/`。逐文件新建并复制字节，不继承工作区安全属性；完整校验后原子发布，复用前再次校验，拒绝符号链接和损坏缓存。升级运行文件会产生新缓存，不覆盖正在使用的版本。

未关闭系统安全功能，未改变全仓 ACL，未重定向 TEMP/TMP，未设置 SQLite temp_store=MEMORY，也未关闭 Chromium 沙箱。诊断中仅对项目 electron.exe 做过完整性对照，已恢复 Low 标记；最终启动不依赖该临时调整。打包安装版不经过本开发启动器。

Windows 完整性机制参考：[Microsoft Mandatory Integrity Control](https://learn.microsoft.com/en-us/windows/win32/secauthz/mandatory-integrity-control)。

## 可复现验收

正常打开应用：

```powershell
npm run dev:desktop
```

真实窗口验收：连续运行两次相同命令，第二次额外检查上次进程写入的正文：

```powershell
npm run gui-check:desktop -- --db-path=C:/Users/压音/AppData/Local/Temp/yfe-窗口验收3/正文.db
```

GUI 检查使用独立 profile，不改用户正常作品记忆；未传 db-path 时在独立临时目录创建新库。默认沙箱第一次 **15 项**、第二次 **16 项**断言全部通过，failedCount=0、exit 0。包括实际编辑器输入与重载，第二次包含 ui.editor.previous-session。

本地原始证据（忽略目录）：

- `.selfcheck/mic-fixed-gui.log`：用户中文目录下默认沙箱的 IPC/正文往返。
- `.selfcheck/mic-editor-gui3.log`：实际界面输入、Ctrl+S、重载。
- `.selfcheck/mic-editor-restart3.log`：整个进程退出后再启动读回正文。
- `.selfcheck/mic-verify.log`：完整代码门禁。
- `_scratch/sqlite-investigation/medium-runtime.json`：同版本运行时恢复 Medium 后中文库/WAL/磁盘临时表因果对照。
- `_scratch/sqlite-investigation/token-electron.log`：原始 Low 进程令牌证据。

本轮验收覆盖 Windows 开发运行链路。实体输入法候选窗、关窗保存失败的原生提示、多平台安装包仍需分别验收。
