## 确定的技术基线

| 范围 | 选择 |
| --- | --- |
| 桌面 | Electron，Windows/macOS/Linux 分平台构建与验收 |
| 桌面及 Web 前端 | Vue 3、TypeScript、Vite；Pinia 管 UI 状态，数据库不放全局响应式大对象 |
| 编辑器 | CodeMirror 6 + 自有 Editor Adapter；首版兼容纯文本正文 |
| 本地及后端业务 | TypeScript，共用可移植应用服务与业务规则 |
| 后端 | Node.js 24 LTS、Fastify 5、OpenAPI、JSON Schema |
| 数据库 | SQLite、版本化 SQL 迁移；桌面/服务端优先 better-sqlite3，经原生模块矩阵验证 |
| 插件 | Cordis + 自有 SDK/权限层；锁定来源，生命周期 API 通过适配层隔离 |
| 并发 | 异步 I/O + 有界 worker_threads；任务状态持久化 |
| 移动 | uni-app x，仅 Android 首发；优先验证受维护的蒸汽模式正式工具链 |
| 原生移动能力 | UTS/Kotlin；SQLite 事务、Android Keystore、WorkManager、系统文件选择 |
| 后端分发 | 单服务 Docker/Compose，linux/amd64 与 linux/arm64 |
| 测试 | 保留旧版测试；新版 Vitest、契约/集成测试、Playwright 桌面与 Web 流程、Android 真机验收 |

Cordis 上游公开说明 API 尚不稳定。此项是本基线中需要额外约束的依赖：不浮动升级，不向第三方暴露 Cordis 类型，P0 验证后锁定包或源码提交；未通过生命周期门禁不能发布稳定版。详细来源与处理见[决策记录](13-决策与资料.md)。

## 首版产品边界

桌面提供完整离线作品管理、写作、基础资料、AI 任务、插件与同步。手机提供配置查看、已缓存内容基础编辑、同步触发、任务查看和经授权的远程控制。Web 管理端管理用户、设备、存储、权限、任务和恢复点，首版不代替完整写作工作台。

不纳入首个稳定版：多人实时共同输入、任意第三方代码无隔离执行、任意编辑器插件跨端直接运行、DLNA 配置同步、所有历史操作系统兼容。所有既有数据仍需可迁移或可保留，不因功能暂未移植而删除。
