## 2. 组件契约（每个面板必须逐字遵守）

```ts
// apps/desktop/src/renderer/panels/types.ts（Lead 独占，别人只读）
export interface PanelProps {
  readonly state: AppState      // 唯一的数据/持久化入口
  readonly tab: TabDef          // 页签元数据（name/description/tips/type/id）
}
```

- 每个面板 = 一个 SFC `apps/desktop/src/renderer/panels/<kebab>.vue`，`defineProps<PanelProps>()`。
- **禁止** `import ... from 'node:*'`、禁止 `fetch`/`WebSocket`（CSP `connect-src 'none'` 会拒）、禁止直接 import `@yfe/persistence-sqlite`/`@yfe/client-sdk` 绕过 `state`。
- 允许：`vue`、`@yfe/ui`、`@yfe/schema-tabs`（类型/常量）、同目录纯逻辑 `.ts`、其他面板的**只读**纯函数（不得改别人的文件）。
- 文案中文；样式只用 `--yfe-*` 令牌并带字面量兜底；组件内不写死大段静态文案（放同级 `.ts` 常量，便于测试与替换）。
- 数据为空 / 未配置模型 / 依赖未实现时，必须**显式**渲染说明（不许静默空白、不许假装成功）。

## 3. 持久化契约（面板自己的数据）

面板数据复用 **settings_entities 通道**（模板 `panel:<tabId>`、名称「面板状态」，跨作品隔离靠 `projectId`），由 Lead 在 `apps/desktop/src/renderer/panels/panel-store.ts` 提供（零后端改动，走 W6 打通的 `listSettingsEntities` / `saveSettingsEntity`）：

```ts
const store = createPanelStore<T>(props.state, props.tab.id, { /* 默认值 */ }, { autoSaveMs? })
store.data       // Ref<T>
store.loading    // Ref<boolean>
store.saving     // Ref<boolean>
store.dirty      // Ref<boolean>   是否有未保存改动
store.error      // Ref<string|null> 最近一次失败的脱敏原因
store.revision   // Ref<string|null> 乐观锁水位
await store.load()            // 只读拉取；失败不覆盖本地 data
store.patch(partial)          // 浅合并并标脏
store.set(next)               // 整体替换并标脏
await store.save()            // 落库；失败写 error，不改 data
store.dispose()               // 取消定时器（面板卸载时必调）
```
- 写入串行（同一 store 内不并发），迟到序号丢弃，失败保留本地数据并给出可读错误。
- ⚠️ `values` 是**整体替换**且 `order_key` 是 BINARY 逐字符比较（R-66/R-69）：面板不要手拼 `orderKey`。
- 面板不得自己拼 IPC 方法名。

## 4. AI 契约（依赖模型的面板）

由 Lead 提供 `state.ai: AiPort`（实现在 `renderer/ai/{types,config,ai-port}.ts`；模型请求只在 **main 进程**发，渲染层 CSP `connect-src 'none'` 禁网）：

```ts
export interface AiRequest {
  readonly system?: string
  readonly messages: readonly { readonly role: 'user' | 'assistant'; readonly content: string }[]
  readonly maxTokens?: number
  readonly temperature?: number
}
export interface AiResult {
  readonly ok: boolean
  readonly text?: string          // ok=true 时必有
  readonly model?: string
  readonly code?: AiErrorCode     // 失败：AI_NOT_CONFIGURED / AI_AUTH_FAILED / AI_RATE_LIMITED / AI_TIMEOUT / AI_UPSTREAM_ERROR / AI_RESPONSE_MALFORMED / AI_CANCELLED
  readonly message?: string
  readonly usage?: { readonly promptTokens?: number; readonly completionTokens?: number }
}
export interface AiPort {
  getConfig(): AiModelConfig | null   // 含 apiKey；面板展示时必须用 redactAiConfig()
  configured(): boolean
  reload(): Promise<boolean>          // 从 settings_entities 重读配置
  saveConfig(next: AiModelConfig): Promise<boolean>
  complete(request: AiRequest): Promise<AiResult>
}
```
- `configured() === false` 时面板必须显示「未配置模型」并提供跳转/提示（`model-settings` 页签），**不得**发起请求。
- **配置按作品存**（与旧版一致）：`saveConfig` 需要当前作品；没有作品时返回 `false`，面板要先引导建作品。
- 展示配置只能用 `redactAiConfig`（apiKey 只显「已配置/未配置」，绝不回显明文——设计文档 11:44）。
- AI 面板的**纯逻辑**（提示词拼装、参数解析、响应解析、流水线状态机）必须放在同级 `.ts` 里并单测；`.vue` 只做渲染与调用。
- 生成类面板必须支持「无模型也能用的本地能力」（如取名生成器、敏感词检测、字数统计）。
