# 测试验收与迁移

## 验证分层

| 层级 | 重点 | 建议工具与产物 |
| --- | --- | --- |
| 领域单元 | 版本、字段、权限、任务状态机、合并 | Vitest、固定数据样本 |
| 契约 | Schema、错误、API/IPC 与移动一致性 | 生成漂移检查、跨端黄金样本 |
| 数据集成 | SQLite 事务、迁移、备份、磁盘故障 | 临时库与故障注入 |
| 插件集成 | 依赖、清理、升级、数据保留与权限 | 专用测试插件、资源计数 |
| 同步集成 | 两端并发、重复/乱序/断流与游标 | 双客户端测试器、模拟 Provider |
| 用户流程 | 建书、编辑、AI 建议稿、冲突与配对 | Playwright Web/桌面适配原型、必要人工流程 |
| 手机 | 真机输入、保存、后台、网络与签名包 | HBuilderX 工具链与 Android 真机日志 |
| 分发 | 干净系统安装、更新、原生模块与恢复 | 三平台 CI 和实际安装证据 |

Electron 自动化适配在 P0 验证其工具限制，不能把自动化无法覆盖的平台行为省掉；输入法、签名、系统权限和后台限制保留人工真机验收。旧版自定义测试继续运行，新版不强迫一次性改写全部旧测试。

## 固定基准与目标

样本包含 1000 章、约 500 万中文字、100 MB 附件、较多关系与动态字段，另测单章 5 千/2 万/5 万字。固定设备、模型、网络、应用与插件版本，至少多次记录中位数与 P95。冷启动从进程创建到可编辑，热启动单列。

以下为 P0 校准的工程目标，尚未取得实测结果。不同平台分别报告，不能以最快设备宣传全平台。

| 指标 | 初始目标与口径 |
| --- | --- |
| 启动 | 指定基准机冷启动到可编辑 P95 争取 ≤3 秒；先测 Electron 空壳与旧版 |
| 输入 | 同时进行两个 AI 请求与索引/同步时，输入处理 P95 <50 ms，无组合态/光标破坏 |
| 保存 | 停止输入到本地事务确认 P95 ≤1 秒；持续输入有最长保存等待与草稿检查点 |
| 内存 | 固定工作区空闲总应用进程内存争取 ≤350 MB，稳定并发负载不持续增长；记录平台统计口径 |
| 包体 | 按平台单架构统计压缩安装包、落地占用、业务资源与可选组件；P0 建基线，后续超出预算 10% 需说明和评审 |
| 同步 | 稳态改一章只传对应变更和新增附件；不重传整库 |
| 正确性 | 已确认保存进程崩溃后可恢复；双端同章修改不静默丢任一版本 |
| 上手 | 目标 5 分钟内建书并保存第一章，不要求预先配 AI/NAS/插件 |
| AI | 固定模型与任务报告质量、Token、首字、耗时、费用、重试和采用率，不牺牲可见性规则换速度 |

Electron 自带运行时，之前 Tauri 的 40 MB/200 MB 预算不适用。包体预算由真实产物确定，而非写一个不能实现的绝对下载量。内存需包括 main、renderer、GPU、服务、DB/CPU workers；macOS/Windows/Linux 的统计口径分别注明。

## 必测故障与一致性

保存：磁盘满、只读目录、写入失败、服务退出、编辑时强制结束进程、快速切章、迟到保存回包。同步：上传中断、确认丢失、重复批次、同 ID 异载荷、乱序依赖、超时、认证失败、远端损坏、时钟偏差、游标过期与长期离线。

冲突：同章双改、删除对编辑、附件引用对删除、字段模板升级、插件数据 Schema 不同。所有场景都能保留双方内容或明确拒绝，不能退化为空库覆盖。网络失败和不存在必须不同类型。

权限：跨用户猜 ID、越权游标/下载、被撤销设备继续推送、过期配对码、重复远程命令、插件权限不足、恶意路径与存储目标。秘密不能出现在日志、普通导出、同步包和错误堆栈。

插件：依赖循环、缺失、激活异常、异步清理、运行任务时禁用、反复启停、迁移失败与降级拒写。主题切换不能改正文；卸载保留数据，缺插件仍可保底阅读/导出。

部署：非 root 卷权限、数据库误挂网络目录、空 key 文件、缺环境变量、启动迁移中断、镜像替换、重启与日志轮转。备份恢复必须在新实例完成正文/引用/附件校验，不能只验证备份文件存在。

## 平台矩阵

Windows x64、macOS arm64/x64、Linux x64 为首发测试范围，Ubuntu/Debian 作为 Linux 基线，其他发行版逐项扩展。每个平台记录最低支持版本、安装包、原生 SQLite 模块、输入法、字体、文件选择、更新和默认权限。Linux arm64 在完成同类验收后发布。

Android 覆盖用户小米真机与一个受支持较低版本/模拟环境。release APK 测基础编辑、离线缓存、后台约束、省电、锁屏、被回收、重连与设备撤销。NAS 覆盖飞牛 WebDAV、容器卷、SMB/NFS 挂载和至少一个 S3 兼容测试服务，驱动声明能力以实测为准。

## 旧版迁移程序

1. 为旧版样本建立可追踪清单：JSON/IndexedDB、sidecar、世界包、图片、快照、知识库、同步文件及未知字段。
2. 只读解析副本，建立旧 ID/字段映射，拒绝读取失败当空；保存原始文件和摘要。
3. 在独立新库导入，报告正文校验、实体数量、引用、附件与暂不支持功能的保留位置。
4. 用户查看差异并主动切换，新旧程序不共用可写目录。切换前备份，迁移期间旧库不被重写。
5. 在新版完成读取、编辑、导出和双端往返，再逐步接管完整业务。回退恢复旧版备份或兼容导出，不让旧程序打开新库。

禁止默认上传用户作品做评测；使用脱敏或人工构造样本。迁移报告必须能解释无法导入字段，不因界面尚未提供功能就删除原数据。

## 发布门禁

保存、同步、迁移、权限或备份恢复出现阻断缺陷，不发布稳定版。三平台构建成功不等于安装验收通过；签名、公证、许可证与更新校验需独立记录。Cordis 固定来源和生命周期回归未完成，不对外承诺稳定插件 API。

每次发布提供应用/协议/数据库/插件 API 版本、兼容范围、测试摘要、安装包摘要、已知限制和回退方法。变更了性能相关实现或发现回归才扩大基准，不无理由反复跑全套昂贵评测。
