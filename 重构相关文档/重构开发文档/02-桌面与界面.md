# 桌面与界面开发设计

## Electron 进程职责

| 进程 | 职责 | 约束 |
| --- | --- | --- |
| main | 窗口、菜单、协议、更新、系统文件选择与进程监督 | 不跑索引、整库解析、同步 SQL 与模型长请求 |
| preload | 类型化白名单桥接 | 不暴露 ipcRenderer、任意 channel、require、shell 或通用文件读写 |
| renderer | Vue 工作区、CodeMirror、交互与状态展示 | nodeIntegration=false、contextIsolation=true、sandbox=true |
| local-service | utilityProcess 内的应用服务、可信 Cordis 插件宿主、网络与数据协调 | 有权限的可信进程，不宣称为第三方代码沙箱 |
| DB worker | 单连接所有者、迁移和短事务 | 连接不跨线程传递；写事务内不等待网络 |
| CPU worker 池 | 分词、解析、校验、向量评分 | 有界队列、超时、取消点；空闲回收 |

utilityProcess 提供 Node 和消息通信能力，适合把服务工作移出 main。其退出由 main 观察；服务重启后根据数据库恢复任务，不根据 UI 内存猜测已完成步骤。[官方 API](https://www.electronjs.org/docs/latest/api/utility-process)

local-service 与 DB worker 分离让同步 SQL 不阻塞 AI 流与网络；首版一个 DB 写连接，读操作也先经该连接排队，证明读负载需要后再增加只读连接。数据库驱动的 Electron ABI、签名和打包路径必须在 P0 验证。

## IPC 契约

桥接按用途暴露 project、document、job、sync、plugin、system 等有限方法。每次请求校验调用窗口、来源、参数 Schema、资源归属和请求大小；通道只接受产品能力，不接受任意 URL+任意请求头的万能代理。

```ts
// 目标产品契约示例，不是当前仓库已有 API。
interface SaveDraft {
  workspaceId: string;
  projectId: string;
  documentId: string;
  expectedRevision: string;
  requestId: string;
  draftSequence: number;
  body: string;
}
type SaveResult =
  | { ok: true; revision: string; draftSequence: number }
  | { ok: false; code: 'REVISION_CONFLICT' | 'DISK_FULL' | 'SERVICE_UNAVAILABLE'; requestId: string };
```

普通命令使用 invoke/reply；流输出通过独立订阅传递任务 ID、序号与片段。订阅返回 disposer，窗口销毁或插件卸载时解除。合并高频流消息，限制队列长度；正文与附件设独立大小限制，不把大文件作为巨型 JSON 在 IPC 反复复制。

保存正常走异步确认；关闭窗口先询问服务未提交草稿状态并等待有限时间，失败时展示恢复选择。保留未确认草稿日志，不把 beforeunload 的同步 IPC 作为日常保存机制。

## 工作区与导航

默认四个入口：作品、写作、资料、任务。设置中集中模型、同步、插件与高级参数；建书无需配置任何网络服务。首屏只引导创建/导入作品并开始第一章。

写作页默认章节树、正文和可折叠资料/AI 面板；工具栏保留高频编辑和一个 AI 入口。人物、大纲、伏笔、世界观由工作区配置决定面板是否展示。插件命令进入命令面板与上下文菜单，不自动增加常驻按钮。

全局命令使用语义 ID，快捷键由平台映射 Ctrl/Cmd，允许重新绑定。支持键盘导航、屏幕阅读标签、可见焦点、高对比和系统字体缩放。同步用“本地已保存、待同步、同步中、冲突、连接失败”分别表示，不能让网络错误覆盖本地保存状态。

## 编辑器

首版 CodeMirror 6，正文以纯文本为兼容基础。Editor Adapter 定义 open、getSelection、applyTransaction、undo/redo、flush、decorate、registerCommand 与 dispose。主题不改变正文，编辑器替换不改变保存和版本语义。

正文不以双向绑定的大字符串在每个键入时整段重建。采用编辑事务与草稿序号，防抖保存并设置最长等待；切章、切作品和退出前冲刷。输入法组合态不被远程事件重置，保存结果只确认对应草稿序号，迟到结果不得覆盖新稿。

外部更新当前章时：没有本地未提交编辑可安全刷新；存在草稿则保留编辑器状态并提示外部版本，进入冲突处理。AI 输出先成为建议稿，采用时生成版本化编辑事务。

中文测试含拼音组合、候选选择、长按、粘贴、撤销、段首缩进、跨段选区、搜索替换和 5 千/2 万/5 万字章节。富文本作为独立格式插件后续提供，先定义导出与转换规则。

## 安全与发布

只加载打包的界面入口，CSP 限制脚本与网络来源；禁止任意导航、新窗口和未校验的外部协议。HTML/Markdown 预览清理脚本和危险 URL。远程网页使用系统浏览器，不能复用有本地能力的编辑器窗口。

凭据通过 main 的系统密钥适配保存；Linux 系统缺少安全存储时明确报告不可安全持久保存，提供仅本次会话输入，不悄悄降级为明文。更新校验来源和签名，升级先备份数据库，失败可安装旧程序并恢复兼容备份。

Windows 首发 x64，macOS 同时规划 arm64/x64 独立产物，Linux 首发 x64，arm64 在原生依赖矩阵通过后加入。三操作系统为必交付范围，CPU 架构以发布矩阵为准。Windows 提供安装包，macOS DMG，Linux 首版 AppImage 与 deb；最低系统版本由所锁定 Electron 支持矩阵和真机验收确定。

## 体积与性能优化

Electron 自带运行时，原 Tauri 方案的 40 MB 目标废止。P0 先测运行时基线、旧版和最小可用新版。按操作系统单架构分发，不打一个包含所有平台的客户端包。

使用构建产物白名单，只打运行依赖；源码、测试、缓存、备份、开发工具和未使用资源不进包。移除重复图标库、字体和编辑器；大型协议连接器、模型、字典与素材按需下载并校验，用户能够离线手动安装。ASAR 只解决打包，不视为加密或免费压缩收益。

按功能懒加载界面与插件；首屏只查询作品概要和当前章。列表虚拟化，索引增量更新，流式渲染按帧合并，不每个 Token 重排全文。普通后台任务不创建隐藏窗口。禁用插件后释放监听、worker、计时器和面板，清理是否成功可诊断。

最终目标及方法见[测试验收](11-测试验收与迁移.md)。任何裁剪都不能破坏 Electron 许可证、安全更新、三平台输入或离线功能。
