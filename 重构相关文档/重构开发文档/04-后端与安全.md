# 后端与安全设计

## 技术与服务职责

采用 Node.js 24 LTS、TypeScript、Fastify 5、SQLite 和 Cordis 适配宿主。后端为模块化单体：用户、设备、工作区、配置、版本、附件、同步、任务和存储共享进程中的应用服务接口，不拆成必须分别安装的微服务。Node 使用受支持 LTS，Fastify 与插件版本一起锁定。[Node 发布政策](https://nodejs.org/en/about/previous-releases)、[Fastify 支持政策](https://fastify.dev/docs/latest/Reference/LTS/)

后端只加载可信内置服务插件。UI 不能直接访问数据库；Fastify 路由完成验证、鉴权和应用调用，业务放 packages/application。桌面 local-service 调用相同用例时注入本地主体与实现，不伪造一个本地 HTTP 登录。

## 身份和设备

首次启动为未初始化状态；一次性引导凭据通过仅管理员可读的秘密文件提供，日志只提示文件位置，不打印秘密值。初始化仅可执行一次，创建所有者后立即禁用引导路径，公开部署在开放入口前完成初始化。

用户密码通过成熟 Argon2id 实现保存摘要，参数随部署硬件基准调整并记录，禁止自制密码学。Web 管理端使用 HttpOnly、Secure、SameSite 会话 Cookie 与 CSRF 校验，客户端原生使用短期访问令牌和可撤销刷新凭据。服务器保存刷新凭据摘要，轮换与重复使用检测在事务中完成。

配对码短期、一次性、限定用户/工作区；手机或桌面确认服务指纹与名称后领取独立 deviceId 和凭据。支持设备重命名、最后活动、撤销与重新配对。撤销的设备不能继续上传；不能远程擦除其已下载的明文副本，管理页应准确说明。

## 权限模型

| 角色 | 首版权限 |
| --- | --- |
| 系统管理员 | 服务设置、用户、存储与运维；内容访问规则单独明确 |
| 工作区所有者 | 管理成员、设备授权范围、恢复点与工作区配置 |
| 编辑者 | 授权作品的编辑、同步和允许任务 |
| 只读者 | 授权内容查询与下载，不提交变更或远程命令 |

角色与资源范围一起判定。所有查询、对象下载、游标、任务订阅和写入均重新鉴权；猜中 documentId、assetHash 或 jobId 不等于有权限。插件令牌与设备令牌不能越过工作区边界。

服务器管理员对其主机数据的实际访问能力不能靠应用角色隔离消除。首版依靠 TLS、磁盘权限与受控密钥存储；如需服务器不可读正文，必须另设计端到端加密。端到端加密后服务器检索和 AI 处理能力需调整，不能同时承诺两种相冲突的能力。

## 数据与配置服务

配置分用户共享、工作区、设备与敏感域。主题、字段模板、工作流、插件清单与明确允许的插件数据支持版本、同步、回滚和导出。路径、窗口布局细节、系统授权与设备凭据不盲目跨端复制。配置提交也走操作日志和版本条件检查。

附件使用内容校验与工作区引用索引。上传临时区、配额和过期清理独立管理；只有校验完成且有权限的对象才能发布引用。跨用户去重不能泄露其他用户是否持有某个文件。

## 任务和远程控制

服务端任务与桌面设备任务共享命令结构，执行目标明确。桌面主动建立认证连接或轮询领取命令，避免要求用户给桌面开放公网端口。

命令包含 commandId、workspaceId、targetDeviceId、commandType、args、expiresAt、issuer 与状态。允许的 commandType 首版为 workflow.run、job.cancel、sync.trigger；参数由对应 Schema 校验。生成命令时与执行前都检查权限和有效期。客户端不能提交自报 issuer；服务端从会话产生。

命令领取使用租约，回执携带 executionId；重复投递只返回原执行结果，不重新调用模型。过期命令不执行，取消不承诺撤销已经发送的外部请求。桌面离线显示 queued/offline/expired，只有后端执行目标才能在桌面关闭时继续运行。

## 接口安全与运维

HTTP API 前缀 /api/v1，Schema 验证输入和输出，统一错误、分页和大小限制；详见[同步与 API](07-同步协议与API.md)。登录、配对、上传、任务与模型调用分别限流。代理部署仅信任配置过的代理层，不能盲目信任所有 X-Forwarded-*。

存储连接探测只允许管理员选择范围。私有网段是 NAS 的正常用途，因此不一概禁止内网连接，但须把管理员批准的目标与普通插件可访问域分开；重定向重新验证、阻止云元数据入口与越界目标，避免通用代理形成 SSRF。文件操作校验规范化路径、符号链接和根目录边界。

凭据使用 secretRef 引用，由凭据服务读取；插件、错误与日志不包含密钥。服务器加密保存秘密时，主密钥通过只读 secret 文件注入并独立备份，不和数据库一起以明文导出。

健康接口区分 live 与 ready：进程存活、数据库可用、迁移状态、磁盘与队列状态。日志输出 JSON，requestId 串联请求、任务和操作；审计记录登录、设备撤销、权限修改、插件授权、远程命令与恢复操作，不默认收集正文。

优雅停止先拒绝新任务，等待短事务和检查点，保存租约状态再关闭数据库。崩溃恢复识别过期租约和未知外部调用结果。单实例 SQLite 不能启动多个独立 writer 服务副本；扩容前切换经迁移验证的存储实现。
