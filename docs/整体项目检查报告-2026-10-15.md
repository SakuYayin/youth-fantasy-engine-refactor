## 结论

已完成一轮跨模块通读、交叉审查、缺陷修复和集中回归。**Electron 默认沙箱真窗口及正文编辑/保存/重启恢复验收已通过**。完整产品交付仍受下列移动端、实际 Docker 镜像等阶段性边界限制。

本项目是本地优先的小说创作管理应用，采用 npm workspaces、TypeScript、Vue 3/CodeMirror 6、Electron 和 SQLite，另有 Fastify 模块化后端。当前桌面通过 child_process 运行 DB worker；worker 兼容 utilityProcess 通信，但主进程尚未切到 utilityProcess。Android uni-app x 是规划目标，本轮只有跨端契约与架构约束，未验证移动端实现。

## 已修复问题

| 范围 | 缺陷及修复 |
| --- | --- |
| 保存与事务 | 丢失回执后携原版本重试被误报冲突；同草稿序号换正文假报成功；事务返回 Err 时仍可能提交部分改动。现先授权再核对重放身份，失败强制回滚。 |
| 修订身份 | 默认序号编码在离线副本上碰撞。新增随机修订标识，保留内部整数排序和旧格式读取；见 ADR 0007。 |
| 请求幂等 | 同键并发创建重复实体、真实桌面未接账本。应用按端口/键排队；桌面命令与本地回执同事务持久化；回执不进入 outbox。真实 worker 重启后仍可重放；回执落盘失败时实体也回滚。 |
| 恢复/迁移 | 覆盖恢复失败丢失原库；路径别名破坏源备份；活动日志混入；迁移清理误删其他库、重名耗尽后删除旧备份。现保留原文件并在失败时还原，收窄路径与清理范围；未确认的空正文也可恢复。 |
| 桌面桥与来源 | 沙箱 preload 错误 require 本地文件导致桥无法注入。现自包含且有受限环境执行测试；IPC 仅接受可信主窗口主框架，导航按 URL 精确校验，外链限制 HTTP(S)。 |
| 桌面生命周期 | 首次启动未构建、继承 Node 模式、GUI 检查可能无界等待、worker 重启后未重开库。启动器先构建并清理运行标志；检查有期限；重启恢复原库后才放行请求。 |
| 编辑与退出 | 保存失败仍切章/新建而丢稿；旧回执回退版本/字数；冲突和错误序号导致 flush 卡住；同章外部内容未反映到编辑器；组合态切章串写。现检查保存结果、作废旧请求、等待导航收束；组合态拒绝切换，导航期间只读且不重建撤销历史。关窗等待 renderer 冲刷，失败时保留继续编辑入口。 |
| 同步与后端 | opId 漏校验目标身份，历史重放可倒退批内基线；`__proto__` 在规范化时丢字段。现完整比对身份并保持当前基线，规范化使用无原型对象。 |
| 附件与事件 | 上传异常永久卡 completing、异步异常未映射、资产与完成标记不原子；SSE 撤权后继续输出；无文件名 HTML 可同源内联。现异常解锁与事务化登记、I/O 后和每轮流读取前重新授权、附件强制下载。 |
| 后端恢复 | 替换失败丢旧文件、并发恢复同目标、在线覆盖主库/WAL/SHM。现保留回滚副本、同目标互斥并拒绝在线覆盖活动主库。 |
