# 酒馆组 · 原版 vs 现版还原差距报告（8 页签）

- 分析范围：旧版（React，只读参考）`_upstream_tmp\youth-fantasy-engine-main\src` × 新版（Vue 3）`apps\desktop\src\renderer`
- 对照方法：逐文件精读旧版 `lib\tavern` 全部 39 个文件头部 + 核心文件（engine/store/prompt/worldBook/settings 等）正文，grep 核实（含 `eval|new Function`、`avatar`、`stream|onToken|AbortController` 三项专项核实）；新版逐个读 `panels\tavern-*.model.ts` 8 份 + `tavern\types.ts`
- 级别：**已还原**（行为等价）/ **简化**（有对应物但缺关键块）/ **未实现**（现版完全没有）
- 纪律：本报告只做分析不改代码；上游引用一律带文件路径，关键处带行号

|---|---|---|
